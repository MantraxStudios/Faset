Generador pseudoaleatorio xorshift64\*: rápido y reproducible con la misma semilla. **No** es apto
para criptografía.

```faset
using std.random;
using std.collections;

int main()
{
    Random rng = new Random(1234);           // misma semilla, misma secuencia
    println(rng.Next(1, 7));                 // dado: [1, 7)
    println(rng.NextDouble());

    auto cartas = new List<int>();
    for (int i = 0; i < 52; i++) cartas.Add(i);
    Random azar = Random.FromTime();
    for (int i = 51; i > 0; i--)             // Fisher-Yates sobre una List<T>
        Algorithms.Swap<int>(cartas[i], cartas[azar.Next(i + 1)]);
    return 0;
}
```

`Shuffle<T>(T* datos, int n)` baraja un arreglo crudo y, como recibe un puntero, se llama desde un
contexto `memory_unsafe`.
