Generador pseudoaleatorio xorshift64\*: rápido y reproducible con la misma semilla. **No** es apto
para criptografía.

```faset
using std.random;

int main()
{
    Random rng = new Random(1234);           // misma semilla, misma secuencia
    println(rng.Next(1, 7));                 // dado: [1, 7)
    println(rng.NextDouble());

    int* cartas = new int[52];
    for (int i = 0; i < 52; i++) cartas[i] = i;
    Random azar = Random.FromTime();
    azar.Shuffle<int>(cartas, 52);
    delete[] cartas;
    return 0;
}
```
