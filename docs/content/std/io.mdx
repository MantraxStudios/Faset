Archivos, carpetas y rutas, igual en Linux y en Windows: las rutas son UTF-8 (en Windows se usan
las API W de Win32 y se aceptan `/` y `\`) y las fechas son milisegundos Unix (UTC). Las funciones
devuelven `bool` o `null` en lugar de lanzar excepciones (Faset no tiene excepciones).
`File.ReadAllTextAsync`, `WriteAllTextAsync` y `AppendAllTextAsync` devuelven una `Task` para usar con
[`await`](/lenguaje/async/) (la operación corre en el grupo de hilos de `std.task`).

```faset
using std.io;
using std.collections;

int main()
{
    string tmp = Directory.CreateTemp("demo-");       // carpeta temporal única
    string log = Path.Combine(tmp, "log.txt");
    File.WriteAllText(log, "uno\ndos\n");

    FileStream f = File.OpenAppend(log);              // null si no se puede abrir
    f.WriteLine("tres");
    delete f;                                         // escribe lo pendiente y cierra

    FileStream r = File.OpenRead(log);
    string line;
    while (r.ReadLine(out line)) println(line);
    delete r;                                         // cierra ya (si no, al recogerlo el recolector)

    println(File.GetSize(log));                       // 13
    Directory.Delete(tmp);                            // recursivo; no sigue enlaces
    return 0;
}
```

`FileWatcher` avisa de los cambios en una carpeta: usa inotify en Linux y compara instantáneas
(`PollIntervalMs`) en el resto de sistemas.

```faset
using std.io;
using std.collections;

int main()
{
    string dir = Directory.CreateTemp("vigilada-");
    auto watcher = new FileWatcher(dir, true);         // true: también subcarpetas
    string nuevo = Path.Combine(dir, "nuevo.txt");
    File.WriteAllText(nuevo, "hola");

    auto cambios = new List<FileChange>();
    watcher.WaitForChanges(cambios, 1000);             // espera hasta 1 s
    for (int i = 0; i < cambios.Count; i++) println(Path.GetFileName(cambios[i].Path));

    delete watcher;                                    // deja de vigilar
    Directory.Delete(dir);
    return 0;
}
```

- `File.Copy`/`File.Move`/`Directory.Move` fallan si el destino existe (como en C#), salvo con
  `overwrite = true`. `Directory.Create` crea las carpetas intermedias.
- `File.ReadAllLines`, `Directory.GetFiles(dir, "*.fst", true)` y similares devuelven listas de
  copias; `File.FreeLines`, `Directory.FreeList` y `FileWatcher.FreeChanges` ya no hacen falta (la
  memoria la recupera el recolector).
