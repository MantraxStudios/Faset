Herramientas de memoria al estilo C++: `Span<T>` (puntero + longitud con comprobación de límites),
`Arena` (muchas reservas pequeñas en bloques grandes) y `Box<T>` (un valor en el heap, como `unique_ptr`).
La memoria la sigue recuperando el [recolector de basura](/lenguaje/memoria/).
Como trabajan con punteros, sus miembros con punteros en la firma solo se usan desde un contexto
[`memory_unsafe`](/lenguaje/seguridad-de-memoria/).

```faset
using std.mem;

int main()
{
    memory_unsafe
    {
        int* datos = new int[8];
        Span<int> s = new Span<int>(datos, 8);
        s.Fill(7);
        Span<int> mitad = s.Slice(4);
        mitad[0] = 1;                        // fuera de rango: panic con mensaje
        println(datos[4]);                   // 1

        auto arena = new Arena();
        double* v = arena.NewArray<double>(1000);
        v[999] = 3.5;
        println(arena.BytesUsed > 0);
    }
    return 0;
}
```
