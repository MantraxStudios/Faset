Colecciones genéricas escritas en Faset. Son clases: se crean con `new` y el
[recolector de basura](/lenguaje/memoria/) las recupera, junto con su memoria interna, cuando dejan
de usarse. Como en C++, las plantillas se comprueban al usarse:
`List<T>.Sort()` solo exige `operator<` si la llamas.

```faset
using std.collections;

bool EsPar(int x) => x % 2 == 0;
int AlCuadrado(int x) => x * x;

int main()
{
    auto lista = new List<int>();
    for (int i = 1; i <= 10; i++) lista.Add(i);
    lista[0] = 100;                          // operator[] devuelve T&

    auto pares = lista.Where(&EsPar);        // punteros a función en lugar de lambdas
    auto cuadrados = pares.Select<int>(&AlCuadrado);
    println(cuadrados.Sum());

    auto edades = new Dictionary<string, int>();
    edades["Ana"] = 31;                      // inserta o modifica, como en C++
    edades["Luis"] += 1;                     // una clave nueva empieza en default(V)
    println(edades.GetOrDefault("Eva", -1));
    return 0;
}
```

`List<T>`, `Dictionary<K, V>`, `HashSet<T>`, `Stack<T>` y `Queue<T>` implementan `IEnumerable<T>`:
se pueden pasar a cualquier parámetro `IEnumerable<T>` y reciben el [LINQ perezoso](/lenguaje/linq/)
de `Enumerable` (`Enumerable.Range`, `Take`, `Zip`, `GroupBy`...). Los métodos propios de `List<T>`
(`lista.Where(...)`) siguen siendo inmediatos y `foreach` sobre una colección concreta usa su
enumerador `struct`, sin reservar memoria. Para escribir secuencias propias con `yield return`, ver
[Iteradores y yield](/lenguaje/iteradores/).
