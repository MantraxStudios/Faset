# Pestañas y árboles

<p className="lead">
  <code>&lt;TabControl&gt;</code> reparte controles en páginas con pestañas y <code>&lt;TreeView&gt;</code>
  muestra una jerarquía de nodos que se expanden y contraen. Los dos se describen anidando elementos en el
  <code>.fstui</code> y se pueden ampliar desde el código.
</p>

## `TabControl` y `TabPage`

Cada `<TabPage>` es un contenedor que ocupa el área bajo las pestañas; solo se ve la página elegida.
Los controles de una página van dentro de su `<TabPage>`, con coordenadas relativas a ella:

```fstui
<TabControl Name="tabs" X="252" Y="46" Width="632" Height="470" Anchor="Left,Top,Right,Bottom" SelectedChanged="OnPestana">
  <TabPage Name="pagImagenes" Text="Imágenes">
    <PictureBox Name="picPaisaje" X="16" Y="16" Width="360" Height="230" Source="Assets/paisaje.jpg" SizeMode="Zoom" />
  </TabPage>
  <TabPage Name="pagLienzo" Text="Lienzo">
    <Canvas Name="lienzo" X="12" Y="12" Width="606" Height="404" Anchor="Left,Top,Right,Bottom" Paint="OnPintar" />
  </TabPage>
  <TabPage Name="pagFormulario" Text="Formulario">
    <TextBox Name="txtNombre" X="20" Y="44" Width="300" Height="36" Placeholder="Escribe tu nombre..." />
  </TabPage>
</TabControl>
```

| Elemento | Atributos propios |
|---|---|
| `<TabControl>` | Los [comunes](/ui/fstui/#atributos-comunes), `SelectedIndex` (página inicial), `Accent` (subrayado de la pestaña elegida), `ContextMenu`, evento `SelectedChanged` |
| `<TabPage>` | `Name`, `Text` (título de la pestaña), `Enabled`, `Background`, `Background2`, `GradientDirection`. No lleva `X`/`Y`/`Width`/`Height`: su tamaño lo decide el `TabControl`. |

Reglas de anidamiento (el compilador las comprueba y señala la línea):

- un `<TabControl>` solo contiene `<TabPage>`;
- un `<TabPage>` solo puede ir dentro de un `<TabControl>`;
- `<Window>`, `<Panel>` y `<TabPage>` son los únicos que contienen controles.

El usuario cambia de página con un clic en la pestaña, con <Kbd>←</Kbd>/<Kbd>→</Kbd> si el
`TabControl` tiene el foco, o con <Kbd>Ctrl+Tab</Kbd> / <Kbd>Ctrl+Shift+Tab</Kbd> desde cualquier
control de la página. Cada cambio hecho por el usuario lanza `SelectedChanged`:

```fst
void OnPestana(Widget sender) { lblEstado.Text = "Pestaña: " + tabs.SelectedPage.Text; }
```

### Desde el código

| Miembro de `Widget` | Descripción |
|---|---|
| `SelectedIndex` | Página elegida (asignarlo cambia de página **sin** lanzar `SelectedChanged`). |
| `SelectedPage` | El `TabPage` elegido (también se puede asignar). |
| `PageCount`, `Page(i)` | Número de páginas y página `i`. |
| `AddPage("Título")` | Añade una página y la devuelve: es un contenedor, así que se le añaden controles con `Add`. |
| `TabAt(x, y)` | Índice de la pestaña bajo un punto de la ventana, o `-1`. |

```fst
Widget tabs = window.Add(Widget.Create(WidgetKind.TabControl, "tabs", 10, 40, 400, 300));
Widget general = tabs.AddPage("General");
general.Add(Widget.Create(WidgetKind.Label, "", 10, 10, 200, 24)).Text = "Página general";
tabs.AddPage("Avanzado");
tabs.SelectedIndex = 1;
```

## `TreeView` y `TreeNode`

```fstui
<TreeView Name="tvProyecto" X="16" Y="46" Width="220" Height="470" Anchor="Left,Top,Bottom"
          ContextMenu="menuArbol" SelectedChanged="OnNodo" NodeActivated="OnNodoActivado">
  <TreeNode Text="Proyecto" Expanded="true">
    <TreeNode Text="src" Expanded="true">
      <TreeNode Text="Program.fst" Tag="src/Program.fst" />
      <TreeNode Text="MainWindow.fst" Tag="src/MainWindow.fst" />
    </TreeNode>
    <TreeNode Name="nodoAssets" Text="Assets">
      <TreeNode Text="paisaje.jpg" Tag="Assets/paisaje.jpg" />
    </TreeNode>
    <TreeNode Text="README.md" />
  </TreeNode>
</TreeView>
```

| Elemento | Atributos propios |
|---|---|
| `<TreeView>` | Los [comunes](/ui/fstui/#atributos-comunes), `ContextMenu`, eventos `SelectedChanged` y `NodeActivated` |
| `<TreeNode>` | `Name`, `Text`, `Expanded` (`true` muestra sus hijos), `Tag` (texto libre: una ruta, un identificador…). Solo va dentro de un `<TreeView>` o de otro `<TreeNode>`. |

Un `<TreeNode>` **no es un `Widget`**: con `Name`, el compilador genera un campo de tipo `TreeNode`
(en el ejemplo, `nodoAssets`).

| Evento | Cuándo |
|---|---|
| `SelectedChanged` | El usuario elige otro nodo (`SelectedNode` cambia). |
| `NodeActivated` | Doble clic o <Kbd>Intro</Kbd> sobre un nodo. |

Teclado: <Kbd>↑</Kbd>/<Kbd>↓</Kbd>, <Kbd>Inicio</Kbd>/<Kbd>Fin</Kbd>; <Kbd>→</Kbd> expande (o baja al
primer hijo), <Kbd>←</Kbd> contrae (o sube al padre), <Kbd>Espacio</Kbd> expande o contrae e
<Kbd>Intro</Kbd> activa.

```fst
void OnNodo(Widget sender)
{
    TreeNode n = tvProyecto.SelectedNode;
    if (n != null) lblEstado.Text = "Nodo: " + n.FullPath;     // Proyecto/src/Program.fst
}

void OnNodoActivado(Widget sender)
{
    TreeNode n = tvProyecto.SelectedNode;
    if (n == null || n.Tag.Length == 0) return;
    lblEstado.Text = "Abierto: " + n.Tag;
}
```

### Desde el código

| `Widget` (el `TreeView`) | Descripción |
|---|---|
| `Nodes` | Nodos de primer nivel (`List<TreeNode>`). |
| `AddNode("texto")` | Añade un nodo de primer nivel y lo devuelve. |
| `RemoveNode(nodo)`, `ClearNodes()` | Quita un nodo de primer nivel o todos. |
| `ExpandAll()`, `CollapseAll()` | Expande o contrae todo el árbol. |
| `SelectedNode` | Nodo elegido (`null` = ninguno). Asignarlo expande sus padres, lo hace visible y **no** lanza `SelectedChanged`. |

| `TreeNode` | Descripción |
|---|---|
| `Text`, `Tag`, `Expanded` | Texto, dato libre y estado. |
| `Nodes`, `Parent`, `TreeView`, `Level` | Hijos, padre (`null` en el primer nivel), el `TreeView` al que pertenece y profundidad (0 en el primer nivel). |
| `FullPath` | Textos desde la raíz separados por `/`. |
| `Add("texto")`, `Remove(hijo)`, `Clear()` | Añadir y quitar hijos. |
| `Expand()`, `Collapse()`, `Toggle()`, `ExpandAll()`, `CollapseAll()` | Expandir y contraer (`ExpandAll` incluye a los descendientes). |

```fst
TreeNode docs = tvArchivos.AddNode("Documentos");
docs.Add("carta.txt").Tag = "/home/ana/carta.txt";
TreeNode fotos = docs.Add("fotos");
TreeNode playa = fotos.Add("playa.jpg");
docs.Expanded = true;
println(playa.FullPath);         // Documentos/fotos/playa.jpg
println(playa.Level);            // 2
tvArchivos.SelectedNode = playa; // expande "fotos" y lo muestra

// Borrar el nodo elegido, esté en el nivel que esté:
TreeNode n = tvArchivos.SelectedNode;
if (n.Parent != null) n.Parent.Remove(n);
else tvArchivos.RemoveNode(n);
```

Si se quita el nodo elegido (o uno de sus padres), deja de estar elegido.
