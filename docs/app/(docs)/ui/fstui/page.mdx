# Formato `.fstui`

<p className="lead">
  Un <code>.fstui</code> es un XML con un elemento raíz <code>&lt;Window&gt;</code> y los controles dentro.
  El compilador lo convierte en una mitad de una clase parcial; los errores se señalan con su línea.
</p>

```fstui
<Window Class="MainWindow" Namespace="MiApp" Title="MiApp" Width="560" Height="380" Theme="Dark">
  <Label Name="lblTitle" X="32" Y="28" Width="496" Height="34" Text="Hello, Faset" FontSize="24" Bold="true" Anchor="Left,Top,Right" />
  <Panel Name="card" X="32" Y="104" Width="496" Height="180" Anchor="Left,Top,Right,Bottom">
    <TextBox Name="txtName" X="20" Y="40" Width="456" Height="36" Placeholder="Type your name..." Changed="OnNameChanged" />
    <CheckBox Name="chkExcited" X="20" Y="92" Width="240" Height="24" Text="Add excitement" Changed="OnNameChanged" />
    <Slider Name="sldVolume" X="20" Y="130" Width="300" Height="24" Value="30" Changed="OnVolumeChanged" />
    <ProgressBar Name="prgVolume" X="336" Y="139" Width="140" Height="6" Value="30" />
  </Panel>
  <Button Name="btnGreet" X="420" Y="312" Width="108" Height="38" Text="Greet" Style="Primary" Anchor="Right,Bottom" Click="OnGreetClick" />
</Window>
```

## `<Window>`

| Atributo | Valor | Descripción |
|---|---|---|
| `Class` | identificador | **Obligatorio.** Nombre de la clase parcial que se genera. |
| `Namespace` | nombre | Namespace de la clase (opcional). |
| `Title` | texto | Título de la ventana (por defecto, el nombre de la clase). |
| `Width`, `Height` | entero | Tamaño inicial (por defecto 800 × 600). |
| `Theme` | `Dark`, `Light` | Tema de colores. |
| `Resizable` | `true`, `false` | Si se puede redimensionar. |
| `MinWidth`, `MinHeight` | entero | Tamaño mínimo. |
| `Background`, `Background2` | color | Fondo; con `Background2`, degradado. Ver [Colores y degradados](/ui/colores/). |
| `GradientDirection` | `Vertical`, `Horizontal` | Dirección del degradado. |

## Controles

| Elemento | Uso | Atributos propios |
|---|---|---|
| `<Label>` | Texto | `Text`, `TextAlign` |
| `<Button>` | Botón | `Text`, `Style`, evento `Click` |
| `<TextBox>` | Entrada de texto de una línea | `Text`, `Placeholder`, evento `Changed` (y `Click` con Intro) |
| `<CheckBox>` | Casilla | `Text`, `Checked`, evento `Changed` |
| `<RadioButton>` | Opción exclusiva | `Text`, `Checked`, `Group`, evento `Changed` |
| `<ComboBox>` | Lista desplegable | `Items`, `SelectedIndex`, evento `Changed` |
| `<ListBox>` | Lista con desplazamiento y teclado | `Items`, `SelectedIndex`, evento `Changed` |
| `<Slider>` | Deslizador | `Value`, `Min`, `Max`, evento `Changed` |
| `<ProgressBar>` | Barra de progreso | `Value`, `Min`, `Max` |
| `<Panel>` | Contenedor de otros controles | — |
| `<PictureBox>` | Imagen PNG, JPEG, BMP o GIF | `Source`, `SizeMode`. Ver [Imágenes](/ui/imagenes/) |
| `<TabControl>` | Páginas con pestañas; contiene `<TabPage>` | `SelectedIndex`, evento `SelectedChanged`. Ver [Pestañas y árboles](/ui/pestanas-y-arboles/) |
| `<TreeView>` | Árbol; contiene `<TreeNode>` | eventos `SelectedChanged` y `NodeActivated` |
| `<MenuBar>` | Barra de menús; contiene `<Menu>` | Ver [Menús](/ui/menus/) |
| `<Canvas>` | Dibujo libre | eventos `Paint`, `MouseDown`, `MouseMove`, `MouseUp`. Ver [Lienzo y temporizador](/ui/lienzo/) |
| `<WebView>` | Navegador web incrustado | `Source`, `Html`, eventos `Navigated`, `TitleChanged`, `MessageReceived`. Ver [WebView](/ui/webview/) |
| `<VideoPlayer>` | Reproductor de vídeo | `Source`, `AutoPlay`, `Loop`, `ShowControls`, `Stretch`, `Volume`, eventos `Opened`, `Ended`, `Failed`. Ver [Vídeo y audio](/ui/multimedia/) |

Los `RadioButton` con el mismo `Group` dentro del mismo contenedor se excluyen entre sí. En
`ComboBox` y `ListBox`, `Items` separa los elementos con `;` (`Items="Rojo;Verde;Azul"`). `Button`
admite además un `Icon` (ver [Imágenes](/ui/imagenes/#iconos-en-botones-y-menus)).

### Elementos que van dentro de otros

| Elemento | Va dentro de | Atributos |
|---|---|---|
| `<TabPage>` | `<TabControl>` | `Name`, `Text`, `Enabled`, `Background`, `Background2`, `GradientDirection` (contiene controles) |
| `<TreeNode>` | `<TreeView>` u otro `<TreeNode>` | `Name`, `Text`, `Expanded`, `Tag` |
| `<Menu>` | `<MenuBar>`, `<ContextMenu>` u otro `<Menu>` | `Name`, `Text`, `Enabled`, `Visible`, `Icon` |
| `<MenuItem>` | igual que `<Menu>` | `Name`, `Text`, `Shortcut`, `Icon`, `Checked`, `Enabled`, `Visible`, evento `Click` |
| `<Separator>` | igual que `<Menu>` | `Name`, `Visible` |

### Componentes

Los componentes no se dibujan en la ventana ni tienen posición: van **directamente dentro de
`<Window>`** y el [diseñador](/studio/disenador/#componentes) los muestra en una bandeja bajo el lienzo.

| Elemento | Uso | Campo generado | Atributos |
|---|---|---|---|
| `<Timer>` | Llama a `Tick` cada `Interval` ms | `Widget` | `Name`, `Interval`, `Enabled`, evento `Tick` |
| `<ContextMenu>` | Menú del botón derecho; contiene `<Menu>`, `<MenuItem>`, `<Separator>` | `Widget` | `Name`, `FontSize` |
| `<Sound>` | Sonido de [`std.audio`](/std/audio/) en memoria | `Sound` | `Name`, `Source`, `Volume`, `Pan`, `Speed`, `Loop`, `AutoPlay` |
| `<Music>` | Música de `std.audio` que se decodifica al sonar | `Music` | los mismos que `<Sound>` |

### Reglas de anidamiento

Solo `<Window>`, `<Panel>` y `<TabPage>` contienen controles. Un `<TabControl>` solo contiene
`<TabPage>`; un `<TreeView>`, solo `<TreeNode>`; un `<MenuBar>` o un `<ContextMenu>`, solo
`<Menu>`, `<MenuItem>` y `<Separator>`. Los componentes no pueden ir dentro de otro control. Cualquier
otra combinación es un error de compilación en la línea del elemento.

## Atributos comunes

| Atributo | Valor | Descripción |
|---|---|---|
| `Name` | identificador | Nombre del campo en la clase. Sin `Name` el control existe pero no es accesible desde el código. |
| `X`, `Y`, `Width`, `Height` | entero | Posición y tamaño, relativos al contenedor (por defecto 0, 0, 100 × 32). |
| `Anchor` | `Left`, `Top`, `Right`, `Bottom` separados por comas | Bordes del contenedor a los que se ancla al redimensionar (por defecto `Left,Top`). |
| `Text` | texto | Texto del control. |
| `FontSize` | entero | Tamaño de letra (por defecto 14). |
| `Bold` | `true`, `false` | Negrita. |
| `TextAlign` | `Left`, `Center`, `Right` | Alineación del texto. |
| `Style` | `Default`, `Primary`, `Subtle`, `Danger` | Estilo predefinido. |
| `CornerRadius` | entero | Radio de las esquinas (por defecto, según el control). |
| `Enabled`, `Visible` | `true`, `false` | Estado. |
| `Value`, `Min`, `Max` | número | Para `Slider` y `ProgressBar` (por defecto 0–100). |
| `ContextMenu` | nombre | `Name` de un `<ContextMenu>` de la ventana que se abre con el botón derecho (ver [Menús](/ui/menus/#menu-contextual)). |
| `Background`, `Background2`, `GradientDirection`, `Foreground`, `BorderColor`, `Accent` | color / dirección | Ver [Colores y degradados](/ui/colores/). |

Los valores se validan al compilar: un número mal escrito, un `Style` desconocido o un atributo que no
existe dan un error en la línea correspondiente del `.fstui`.

## Eventos

| Atributo | En | Firma del manejador |
|---|---|---|
| `Click` | Controles, `MenuItem` | `void Nombre(Widget sender)`: clic, `Espacio`, `Intro` en un `TextBox`, o elegir el elemento de menú. |
| `Changed` | `TextBox`, `CheckBox`, `RadioButton`, `ComboBox`, `ListBox`, `Slider` | `void Nombre(Widget sender)`: cambió el valor. |
| `SelectedChanged` | `TabControl`, `TreeView`, `ListBox`, `ComboBox` | `void Nombre(Widget sender)`: cambió la selección. |
| `NodeActivated` | `TreeView` | `void Nombre(Widget sender)`: doble clic o `Intro` en un nodo. |
| `Tick` | `Timer` | `void Nombre(Widget sender)`. |
| `Paint` | `Canvas` | `void Nombre(Widget sender, Graphics g)`. |
| `MouseDown`, `MouseMove`, `MouseUp` | `Canvas` | `void Nombre(Widget sender, MouseArgs e)`. |
| `Navigated`, `TitleChanged` | `WebView` | `void Nombre(Widget sender)`. |
| `MessageReceived` | `WebView` | `void Nombre(Widget sender, string message)`. |
| `Opened`, `Ended`, `Failed` | `VideoPlayer` | `void Nombre(Widget sender)`. |

Un evento en un control que no lo tiene (`Tick` en un `Button`, `Paint` fuera de un `Canvas`) es un
error de compilación.

El valor es el nombre de un método de la clase con la firma de la tabla:

```faset
using std.ui;

namespace MiApp
{
    public partial class MainWindow
    {
        void OnVolumeChanged(Widget sender) { prgVolume.Value = sldVolume.Value; }
    }
}
```

El [diseñador de FasetStudio](/studio/disenador/) crea el método por ti al hacer doble clic en un control.
