# LINQ

<p className="lead">
  <a href="/std/collections/">std.collections</a> tiene las operaciones de LINQ de C#: filtran,
  transforman, ordenan y agregan con <a href="/lenguaje/lambdas/">lambdas</a>. Hay dos sabores: los
  operadores <strong>perezosos</strong> sobre cualquier <code>IEnumerable&lt;T&gt;</code> (como en
  C#) y los métodos <strong>inmediatos</strong> propios de <code>List&lt;T&gt;</code>, que devuelven
  listas nuevas al momento.
</p>

## LINQ perezoso sobre IEnumerable&lt;T&gt;

`Enumerable` añade los operadores de LINQ como [métodos de extensión](/lenguaje/extensiones/) de
`IEnumerable<T>`: valen para los [iteradores](/lenguaje/iteradores/), para `HashSet<T>`,
`Dictionary<K, V>`, `Stack<T>`, `Queue<T>`, `string` y para cualquier clase que implemente
`IEnumerable<T>`. Los que devuelven una secuencia **no recorren nada** hasta que alguien pide
elementos, y los elementos pasan de uno en uno por toda la cadena:

```faset
using std.collections;

static void Main()
{
    IEnumerable<int> q = Enumerable.Range(1, 6)
        .Where(x => { println("  filtra " + x); return x % 2 == 0; })
        .Select(x => x * x);
    println("nada se ha evaluado aún");
    foreach (int x in q) println("obtiene " + x);
    // filtra 1 / filtra 2 / obtiene 4 / filtra 3 / filtra 4 / obtiene 16 / ...

    println(q.Sum());                                     // 56 (vuelve a recorrer)
    List<int> lista = q.ToList();                         // materializa: [4, 16, 36]
    println(lista.Count);                                 // 3

    HashSet<string> vistos = new HashSet<string>();
    vistos.Add("ana");
    vistos.Add("eva");
    println(vistos.Select(s => s.Length).Sum());          // 6
    println("murciélago".Count(c => "aeiouáéíóú".Contains(c)));   // 5
}
```

Cada recorrido vuelve a evaluar la cadena entera (y vuelve a llamar a las lambdas). Si vas a
recorrer el resultado varias veces, guárdalo con `ToList()`.

| Operador | Resultado |
|---|---|
| `Enumerable.Range(desde, n)`, `Enumerable.Repeat(x, n)`, `Enumerable.Empty<T>()` | Secuencias generadas. |
| `Where(pred)`, `Where((x, i) => ...)`, `Select(f)`, `Select((x, i) => ...)`, `SelectMany(x => secuencia)` | Filtros y proyecciones (perezosos). |
| `Take(n)`, `Skip(n)`, `TakeWhile(pred)`, `SkipWhile(pred)` | Prefijos y sufijos (perezosos: `Take` sirve con secuencias infinitas). |
| `Concat(otra)`, `Append(x)`, `Prepend(x)`, `Zip(otra, f)`, `Zip(otra)` (tuplas) | Combinaciones (perezosas). |
| `Distinct()`, `DistinctBy(clave)`, `Chunk(n)` (trozos `List<T>`), `Reverse()` | Perezosos (`Reverse` lee todo al empezar). |
| `OrderBy(clave)`, `OrderByDescending(clave)`, `.ThenBy(clave)`, `.ThenByDescending(clave)` | Ordenación estable; se ordena al empezar cada recorrido. |
| `GroupBy(clave)` | Grupos `Grouping<K, T>` (con `Key`, `Items` y `Count`; también son `IEnumerable<T>`). |
| `Count()`, `Count(pred)`, `Any()`, `Any(pred)`, `All(pred)`, `Contains(x)` | Recorren en el acto. |
| `First()`, `First(pred)`, `Last(...)`, `ElementAt(i)` | Lanzan `InvalidOperationException` (o `ArgumentOutOfRangeException`) si no hay elemento. |
| `FirstOrDefault(...)`, `LastOrDefault(...)` | O `default(T)`. |
| `Sum()`, `Sum(sel)`, `Min(...)`, `Max(...)`, `Average(...)`, `Aggregate(...)` | Agregados. |
| `ToList()`, `ToHashSet()`, `ToDictionary(clave)`, `ToDictionary(clave, valor)`, `ForEach(accion)` | Materializan el resultado. |

## Dos versiones: inmediata en List&lt;T&gt;, perezosa en IEnumerable&lt;T&gt;

`List<T>` conserva sus propios métodos `Where`, `Select`, `OrderBy`... por compatibilidad y
velocidad: recorren la lista **en el momento** y devuelven una `List<T>` nueva (se puede indexar:
`r[0]`). Como los métodos propios tienen prioridad sobre las extensiones, `lista.Where(...)` es la
versión inmediata. Una `List<T>` usada como `IEnumerable<T>` recibe la perezosa:

```faset
using std.collections;

static void Main()
{
    List<int> l = new List<int>();
    l.Add(1);
    l.Add(5);

    List<int> ahora = l.Where(x => x > 2);                       // inmediata: List<int> ya calculada
    IEnumerable<int> luego = l.AsEnumerable().Where(x => x > 2); // perezosa
    l.Add(9);
    println(ahora.Count + " " + luego.Count());                  // 1 2
}
```

En C# todo LINQ es perezoso; si portas código de C# que depende de esa pereza (secuencias
infinitas, efectos en las lambdas, ver los cambios de la lista), usa `AsEnumerable()` o declara la
variable como `IEnumerable<T>`. Si un método propio no acepta los argumentos (por ejemplo
`diccionario.Count(kv => ...)`, que no encaja con su `Count((k, v) => ...)`), se usa la extensión de
`IEnumerable<T>`, igual que en C#.

## Operaciones inmediatas de List&lt;T&gt;

```faset
using std.collections;

class Producto
{
    public string Nombre;
    public string Tipo;
    public double Precio;
    public Producto(string n, string t, double p) { Nombre = n; Tipo = t; Precio = p; }
}

int main()
{
    var ps = new List<Producto>();
    ps.Add(new Producto("pera", "fruta", 1.5));
    ps.Add(new Producto("queso", "lácteo", 7.0));
    ps.Add(new Producto("uva", "fruta", 3.0));
    ps.Add(new Producto("leche", "lácteo", 0.9));

    var baratos = ps.Where(p => p.Precio < 2).Select(p => p.Nombre);
    println(baratos[0] + ", " + baratos[1]);                // pera, leche

    var orden = ps.OrderBy(p => p.Tipo).ThenByDescending(p => p.Precio);
    println(orden[0].Nombre);                               // uva

    println(ps.Sum(p => p.Precio));                         // 12.4
    println(ps.Count(p => p.Tipo == "fruta"));              // 2
    println(ps.Any(p => p.Precio > 5));                     // true
    println(ps.MaxBy(p => p.Precio).Nombre);                // queso

    var grupos = ps.GroupBy(p => p.Tipo);
    for (int i = 0; i < grupos.Count; i++)
        println(grupos[i].Key + ": " + grupos[i].Count);    // fruta: 2 / lácteo: 2
    return 0;
}
```

Cada operación recorre la lista **en el momento** y devuelve una lista nueva; la original no cambia.
Encadenar `Where(...).Select(...)` crea una lista intermedia. Para colecciones grandes en bucles
críticos, un `for` es más rápido.

| Operación | Resultado |
|---|---|
| `Where(x => ...)`, `Where((x, i) => ...)` | Elementos que cumplen la condición (con su índice). |
| `Select(x => ...)`, `Select((x, i) => ...)` | Lista transformada (`List<U>`). |
| `SelectMany(x => lista)` | Aplana las listas que devuelve la función. |
| `OrderBy(clave)`, `OrderByDescending(clave)` | Ordenación **estable** por clave (la clave necesita `<`; `string` compara por orden). |
| `ThenBy(clave)`, `ThenByDescending(clave)` | Criterio secundario, justo después de `OrderBy`. |
| `First(pred)`, `Last(pred)` | Primer/último que cumple; `panic` si no hay ninguno. |
| `FirstOrDefault()`, `FirstOrDefault(pred)`, `LastOrDefault(...)` | Igual, o `default(T)`. |
| `Any()`, `Any(pred)`, `All(pred)`, `Count(pred)` | Comprobaciones y recuento (`Count` sin paréntesis es el total). |
| `Sum(sel)`, `Min(sel)`, `Max(sel)`, `Average()`, `Average(sel)` | Agregados con selector (`Sum()`, `Min()`, `Max()` sin selector suman/comparan los elementos). |
| `MinBy(clave)`, `MaxBy(clave)` | El elemento con la clave mínima/máxima. |
| `Distinct()` | Sin repetidos, en orden de aparición (`T` necesita `Hash.Of`). |
| `Take(n)`, `Skip(n)`, `TakeWhile(pred)`, `SkipWhile(pred)` | Prefijos y sufijos. |
| `GroupBy(clave)` | `List<Grouping<K, T>>` con `Key`, `Items` y `Count`, en orden de aparición. |
| `ToList()`, `ToDictionary(clave)`, `ToDictionary(clave, valor)` | Copias. |
| `Aggregate((a, b) => ...)`, `Aggregate(semilla, (acc, x) => ...)` | Acumulación de izquierda a derecha. |
| `Zip(otra, (a, b) => ...)` | Combina elemento a elemento. |
| `Concat(otra)` | Las dos listas seguidas. |

También están los métodos clásicos de `List<T>` de .NET: `Sort(Comparison<T>)` (estable),
`ForEach(Action<T>)`, `Find`, `FindLast`, `FindAll`, `FindIndex`, `Exists`, `TrueForAll`,
`RemoveAll(Predicate<T>)` y `ConvertAll`.

```faset
using std.collections;

int main()
{
    var l = new List<int>();
    for (int i = 1; i <= 10; i++) l.Add(i);

    println(l.Aggregate((a, b) => a * b));            // 3628800
    println(l.Aggregate("", (s, x) => s + x));        // 12345678910
    println(l.Average());                             // 5.5

    var pares = l.Zip(l.Skip(1), (a, b) => a * b);
    println(pares[0] + " " + pares[1]);               // 2 6

    l.Sort((a, b) => b - a);                          // descendente, en el sitio
    println(l[0]);                                    // 10
    println(l.RemoveAll(x => x % 3 == 0));            // 3
    println(l.Find(x => x < 5));                      // 4

    int suma = 0;
    l.ForEach(x => suma += x);
    println(suma);                                    // 37
    return 0;
}
```

## Diccionarios

`Dictionary<K, V>` añade `Pairs()` (una `List<KeyValuePair<K, V>>` con `Key` y `Value`, para usar
LINQ), `ForEach((k, v) => ...)`, `GetOrAdd(clave, k => valor)`, `Any((k, v) => ...)`,
`Count((k, v) => ...)` y `RemoveAll((k, v) => ...)`:

```faset
using std.collections;

int main()
{
    var stock = new Dictionary<string, int>();
    stock.Set("pera", 10);
    stock.Set("uva", 0);
    stock.Set("leche", 4);

    println(stock.Count((k, v) => v > 0));                        // 2
    var agotados = stock.Pairs().Where(p => p.Value == 0).Select(p => p.Key);
    println(agotados[0]);                                         // uva
    println(stock.GetOrAdd("queso", k => k.Length));              // 5
    stock.RemoveAll((k, v) => v == 0);
    println(stock.Count);                                         // 3
    return 0;
}
```

Las versiones con [punteros a función](/lenguaje/delegados/#punteros-a-función-delegate) (`&Funcion`)
de `Where`, `Select`, `Any`, `All`, `Sort` y `ForEach` siguen disponibles para código que hable con C.
