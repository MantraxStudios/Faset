# Limitaciones actuales

<p className="lead">
  Faset 0.2 es joven. Esta es la lista honesta de lo que el compilador rechaza hoy, con el mensaje que
  verás y la alternativa recomendada.
</p>

| No disponible | Alternativa |
|---|---|
| Herencia, `interface`, `virtual`/`override` | Composición y [delegados](/lenguaje/delegados/). Están en la hoja de ruta. |
| `foreach` | `for (int i = 0; i < lista.Count; i++)` |
| Interpolación `$"..."` | Concatenación con `+` (`"x = " + x`) o `StringBuilder` |
| Expresiones `throw` (`x ?? throw ...`) | Una instrucción `throw` (las [excepciones](/lenguaje/excepciones/) sí existen) |
| `is` / `as` | Un campo `Kind` (enum) en tus tipos |
| Operador `??` | `x != null ? x : y` |
| Parámetros con valor por defecto, `params` | Sobrecargas |
| Inicializadores de objeto `new T { X = 1 }` | Constructores |
| Inicializadores de constructor `: this(...)` | Un método privado común |
| Tipos anidados | Tipos en el mismo namespace |
| `using static` | Nombre de la clase delante (`Math.Sqrt`) |
| `goto`, `typeof`, `stackalloc`, `fixed` | — |
| Operadores compuestos sobre propiedades (`p.X += 1`) | `p.X = p.X + 1` |

## Otras notas

- Lambdas y delegados: los delegados son estructurales (`Predicate<int>` y `Func<int, bool>` son el
  mismo tipo); un `delegate` declarado dentro de una clase se usa por su nombre simple (no
  `Clase.Delegado`) y no puede usar los parámetros de tipo de una clase genérica; LINQ evalúa de
  forma inmediata (sin `IEnumerable<T>`) y `Distinct`/`GroupBy`/`ToDictionary` necesitan claves con
  `Hash.Of` (números, `char`, `bool`, `string`).

- No hay literales octales: `0777` es decimal (como en C#); usa `0x1FF`.
- C no fija el orden de evaluación de los operandos: evita expresiones como `a[f()] = g()` cuando
  `f` y `g` tienen efectos que dependen entre sí.
- Una carrera de datos sobre una misma variable `string` (dos hilos escribiéndola sin cerrojo) puede
  dejar una cadena a medio escribir, y el código `memory_unsafe` no se comprueba; consulta lo que
  [no cubre la seguridad de memoria](/lenguaje/seguridad-de-memoria/#lo-que-no-cubre).
- El recolector de basura es conservador y no mueve los objetos: un valor entero que por casualidad
  parezca una dirección del heap puede mantener vivo un bloque que ya no se usa.
- Los bindings de Win32 y de Android más allá de `std.ui` no vienen incluidos: se declaran con
  `extern` dentro de código `memory_unsafe`.
- `std.thread` y `std.net` en Windows suponen x86-64/ARM64 (los `extern` no declaran `__stdcall`).
  Varios hilos que escriben con `println` a la vez pueden intercalar líneas: protégelo con un `Mutex`.
- `std.net` no tiene HTTPS/TLS, proxies, compresión ni keep-alive.
- Android: `std.ui` no conoce los recortes de la pantalla (la barra de navegación se dibuja encima)
  ni redimensiona la ventana cuando aparece el teclado. Consulta [Android](/android/#limitaciones).
- FasetStudio funciona en Linux (X11/XWayland); las aplicaciones `std.ui` funcionan en Linux, Windows
  y Android.
