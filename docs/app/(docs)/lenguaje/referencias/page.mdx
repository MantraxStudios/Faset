# Referencias, `ref` y `out`

<p className="lead">
  Una referencia <code>T&amp;</code> es un alias de otra variable, como en C++. Los modificadores
  <code>ref</code> y <code>out</code> de C# son la misma idea escrita a la manera de C#.
</p>

## `T&` al estilo C++

```faset
void Incrementar(int& x) { x++; }

int main()
{
    int a = 5;
    Incrementar(a);          // no hace falta marcar el argumento
    int& r = a;              // referencia local
    r += 10;
    println(a);              // 16
    return 0;
}
```

Las referencias sirven en parámetros, en valores de retorno (`T& operator[](int i)`) y en variables
locales.

Una referencia devuelta debe apuntar a algo que siga vivo al salir del método: un campo `static`,
un campo de un objeto de clase o un parámetro `ref`. Devolver una referencia a una variable local, a
un campo de un struct local o a un parámetro por valor es un error de compilación
(`no se puede devolver una referencia a la variable local 'x'`); consulta
[Seguridad de memoria](/lenguaje/seguridad-de-memoria/#referencias-a-variables-locales).

## `ref` y `out` al estilo C#

```faset
void Dividir(int a, int b, out int cociente, ref int resto)
{
    cociente = a / b;
    resto = a % b;
}

void Incrementar(int& x) { x++; }

int main()
{
    int q = 0, r = 0;
    Dividir(17, 5, out q, ref r);
    println(q);              // 3
    println(r);              // 2

    int n = 1;
    Incrementar(ref n);      // 'ref' también vale con un parámetro T&
    println(n);
    return 0;
}
```

El patrón `Try...(entrada, out resultado)` es la forma habitual de señalar errores esperados en la
biblioteca estándar (sin el coste de una [excepción](/lenguaje/excepciones/)):

```faset
int main()
{
    double d = 0;
    if (Convert.TryToDouble("3.25", out d)) println(d * 2);
    return 0;
}
```

### `out var`

Como en C#, la variable se puede declarar en el propio argumento: `out var x` toma el tipo del
parámetro y `out int x` lo escribe. La variable sigue visible después de la llamada (también fuera
del `if`):

```faset
void Dividir(int a, int b, out int cociente, out int resto)
{
    cociente = a / b;
    resto = a % b;
}

int main()
{
    if (int.TryParse("41", out var n)) println(n + 1);   // 42
    Dividir(17, 5, out int q, out var r);
    println($"{q} {r}");                                  // 3 2
    return 0;
}
```

Con `out var`, todas las sobrecargas que encajan deben tener el mismo tipo en ese parámetro; si no,
escribe el tipo (`out int x`).
