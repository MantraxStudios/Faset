# Sobrecarga de operadores

<p className="lead">
  Los operadores se declaran como en C# (<code>static T operator +(T a, T b)</code>). La indexación
  usa la forma de C++: <code>T&amp; operator[](int i)</code> devuelve una referencia, así que
  <code>v[i] = x</code> funciona.
</p>

```faset
struct Vec2
{
    public double X, Y;
    public Vec2(double x, double y) { X = x; Y = y; }

    public static Vec2 operator +(Vec2 a, Vec2 b) => new Vec2(a.X + b.X, a.Y + b.Y);
    public static Vec2 operator -(Vec2 a, Vec2 b) => new Vec2(a.X - b.X, a.Y - b.Y);
    public static Vec2 operator -(Vec2 a) => new Vec2(-a.X, -a.Y);          // unario
    public static Vec2 operator *(Vec2 a, double k) => new Vec2(a.X * k, a.Y * k);
    public static Vec2 operator *(double k, Vec2 a) => new Vec2(a.X * k, a.Y * k);
    public static bool operator ==(Vec2 a, Vec2 b) => a.X == b.X && a.Y == b.Y;
}

int main()
{
    Vec2 v = new Vec2(1, 2) + new Vec2(3, 4) * 2.0;
    println(v.X);                       // 7
    println(v == new Vec2(7, 10));      // true
    println(v != new Vec2(0, 0));       // != se deduce de ==
    return 0;
}
```

## Concatenar cadenas con `+`

Como en C#, `+` une cadenas, y `+=` añade al final. Basta con que uno de los dos operandos sea un
`string`; el otro puede ser una cadena, cualquier número, un `char`, un `bool` o un `enum` (que se escribe con su valor numérico), y se
convierte a texto. La cadena resultante se reserva en el heap del [recolector](/lenguaje/memoria/):
no hay que liberarla.

```faset
enum Estado { Listo, Ocupado }

int main()
{
    string t = "a" + 1 + 'b' + 2.5 + true + 3u;
    println(t);                         // a1b2.5True3
    t += "!";
    t += 7;
    println(t);                         // a1b2.5True3!7
    Estado e = Estado.Ocupado;
    println("estado: " + e);            // estado: 1
    return 0;
}
```

Como en C#, la expresión se evalúa de izquierda a derecha: `1 + 2 + "x"` da `"3x"` y `"x" + 1 + 2`
da `"x12"`. Para unir muchas partes en un bucle, `StringBuilder` (en [`std.text`](/std/text/)) evita
crear una cadena intermedia en cada paso.

## Orden de evaluación

Faset garantiza el orden de C#, aunque compila a C (donde el orden de los operandos no está
especificado):

- Los operandos de un operador y los argumentos de una llamada (a un método, un constructor o un
  delegado) se evalúan **de izquierda a derecha**, y el receptor (`obj` en `obj.M(...)`) antes que
  los argumentos.
- En una asignación se evalúa primero el lado izquierdo (el objeto y el índice de `a[i] = ...`), y en
  una asignación compuesta (`+=`, `-=`...) también su valor anterior, antes que el lado derecho. El
  lado izquierdo se evalúa **una sola vez**, también con propiedades, eventos y cadenas.
- Lo mismo vale para la concatenación con `+`, las cadenas interpoladas, las tuplas y `with`.

```faset
using std.collections;

int paso = 0;

int Siguiente(string quien)
{
    paso++;
    println(quien + " " + paso);
    return paso;
}

int main()
{
    int r = Siguiente("a") * 10 + Siguiente("b");   // a 1, b 2
    println(r);                                      // 12

    int i = 0;
    var v = new List<int>();
    v.Add(0);
    v[i++] = i;                                      // v[0] = 1
    int x = 5;
    x = x++;                                         // como en C#: x sigue valiendo 5
    println(v[0] + " " + x);                         // 1 5
    return 0;
}
```

No cuesta nada en el código normal: el compilador solo guarda un operando en un temporal cuando
otro posterior puede cambiar lo que lee (una llamada, una asignación, `++`, `new`...). Las llamadas
a métodos que no escriben nada (como `Math.Sqrt` o un `get` que solo devuelve un campo) no obligan
a reordenar.

## Indexación con referencias

```faset
// La implementación usa punteros (memory_unsafe), pero su API pública no:
// Rejilla es un envoltorio seguro y se usa desde código normal.
memory_unsafe class Rejilla
{
    int ancho;
    int* celdas;

    public Rejilla(int w, int h) { ancho = w; celdas = new int[w * h]; }

    public int& operator[](int i) => celdas[i];
}

int main()
{
    auto r = new Rejilla(4, 4);
    r[5] = 42;              // asigna a través de la referencia
    r[5] += 1;
    println(r[5]);          // 43
    return 0;
}
```

`List<T>`, `Span<T>` y `Dictionary<K, V>` de la biblioteca estándar usan exactamente este mecanismo.

## Operadores que se pueden sobrecargar

| Tipo | Operadores |
|---|---|
| Aritméticos | `+` `-` `*` `/` `%` (y `-` unario) |
| Comparación | `==` `!=` `<` `>` `<=` `>=` |
| Bits | `&` `\|` `^` `<<` `>>` `~` |
| Lógicos | `!` |
| Indexación | `[]` (con retorno `T&`) |

<Callout type="nota">
Si defines `==`, `!=` se obtiene automáticamente. La biblioteca estándar usa `operator<` para
ordenar y `operator==` para buscar (`List.Sort`, `List.Contains`, `Algorithms.BinarySearch`).
</Callout>
