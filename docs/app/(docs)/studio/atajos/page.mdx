# Atajos de teclado

## Archivos y navegación

| Atajo | Acción |
|---|---|
| <Kbd>Ctrl+P</Kbd> | Abrir rápido (buscar archivos) |
| <Kbd>Ctrl+N</Kbd> | Nuevo archivo |
| <Kbd>Ctrl+S</Kbd> | Guardar |
| <Kbd>Ctrl+Shift+S</Kbd> | Guardar todo |
| <Kbd>Ctrl+W</Kbd> | Cerrar pestaña |
| <Kbd>Ctrl+Tab</Kbd> | Cambiar de pestaña |
| <Kbd>{"Ctrl+\\"}</Kbd> | Vista dividida |
| <Kbd>F2</Kbd> | Renombrar (en el explorador) |

## Edición

| Atajo | Acción |
|---|---|
| <Kbd>Ctrl+Z</Kbd> / <Kbd>Ctrl+Y</Kbd> | Deshacer / rehacer |
| <Kbd>Ctrl+F</Kbd> / <Kbd>F3</Kbd> | Buscar / siguiente |
| <Kbd>Ctrl+G</Kbd> | Ir a la línea |
| <Kbd>Ctrl+/</Kbd> | Comentar o descomentar |
| <Kbd>Ctrl+D</Kbd> | Duplicar línea |
| <Kbd>Alt+↑</Kbd> / <Kbd>Alt+↓</Kbd> | Mover la línea (o las líneas seleccionadas) arriba / abajo |
| <Kbd>Alt+Shift+↑</Kbd> / <Kbd>Alt+Shift+↓</Kbd> | Duplicar la línea hacia arriba / abajo |
| <Kbd>Ctrl+↑</Kbd> / <Kbd>Ctrl+↓</Kbd> | Saltar al bloque anterior / siguiente (con <Kbd>Shift</Kbd>, seleccionando) |
| <Kbd>Ctrl+Retroceso</Kbd> / <Kbd>Ctrl+Supr</Kbd> | Borrar la palabra anterior / siguiente |
| <Kbd>Ctrl+L</Kbd> | Seleccionar la línea |
| <Kbd>Ctrl+Intro</Kbd> / <Kbd>Ctrl+Shift+Intro</Kbd> | Insertar una línea debajo / encima |
| <Kbd>Ctrl+Shift+K</Kbd> | Borrar línea |
| <Kbd>Tab</Kbd> / <Kbd>Shift+Tab</Kbd> | Sangrar / quitar sangría (también sobre bloques) |
| Doble / triple clic | Seleccionar palabra / línea |

## IntelliSense

| Atajo | Acción |
|---|---|
| <Kbd>Ctrl+Espacio</Kbd> | Autocompletar |
| <Kbd>F12</Kbd> / <Kbd>Ctrl</Kbd>+clic | Ir a la definición |

## Compilar y ejecutar

| Atajo | Acción |
|---|---|
| <Kbd>Ctrl+B</Kbd> | Compilar |
| <Kbd>F5</Kbd> | Ejecutar |
| <Kbd>Shift+F5</Kbd> | Detener |

## Diseñador

| Atajo | Acción |
|---|---|
| <Kbd>Ctrl+C</Kbd> / <Kbd>Ctrl+X</Kbd> / <Kbd>Ctrl+V</Kbd> | Copiar, cortar y pegar controles |
| <Kbd>Ctrl+D</Kbd> | Duplicar control |
| <Kbd>Supr</Kbd> | Borrar control |
| <Kbd>Tab</Kbd> | Siguiente control |
| <Kbd>Ctrl+↑</Kbd> / <Kbd>Ctrl+↓</Kbd> | Traer al frente / enviar al fondo |
| Flechas (<Kbd>Shift</Kbd>: ×8) | Mover |
| <Kbd>G</Kbd> | Mostrar u ocultar la cuadrícula |
| <Kbd>Ctrl</Kbd> + rueda | Zoom |
| Botón central + arrastrar | Desplazar el lienzo |
| <Kbd>Ctrl</Kbd> al arrastrar | Sin ajuste a cuadrícula ni guías |
| <Kbd>Ctrl+0</Kbd> | Zoom al 100 % |

## Panel Device (Android)

| Entrada | En el dispositivo |
|---|---|
| Clic | Toque |
| Mantener pulsado | Pulsación larga |
| Arrastrar | Deslizar |
| Rueda | Desplazamiento |
| Teclado (con el panel enfocado) | Texto, <Kbd>Retroceso</Kbd>, <Kbd>Supr</Kbd>, <Kbd>Intro</Kbd>, <Kbd>Tab</Kbd>, flechas; <Kbd>Esc</Kbd> = atrás |
