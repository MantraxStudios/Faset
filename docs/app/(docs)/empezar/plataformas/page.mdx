# Plataformas y compilación cruzada

<p className="lead">
  Como Faset genera C11 portable, cambiar de plataforma es cambiar de compilador de C. Con
  <code>--target</code> y <code>--arch</code> eliges el destino y <code>faset</code> busca el compilador adecuado.
</p>

```bash
faset build                              # la máquina actual
faset build --target windows             # .exe con MinGW-w64
faset build --target windows --arch x86  # Windows de 32 bits
faset build --target android            # APK firmado (arm64-v8a + x86_64 por defecto)
faset build --target android --arch arm64 --no-apk   # ELF suelto para adb push
faset build --target linux --arch arm64  # Linux ARM64 (aarch64-linux-gnu-gcc)
```

## Qué compilador se usa

| Objetivo | Compilador buscado |
|---|---|
| El de la máquina | `cc`, `gcc` o `clang` |
| `windows` | `<triple>-gcc` o `<triple>-clang` con `x86_64-w64-mingw32`, `i686-w64-mingw32` o `aarch64-w64-mingw32` |
| `linux` (cruzado) | `aarch64-linux-gnu-gcc`, `arm-linux-gnueabihf-gcc`, `i686-linux-gnu-gcc` o `x86_64-linux-gnu-gcc` |
| `android` | `clang` del NDK: `<triple><api>-clang` en `toolchains/llvm/prebuilt/<host>/bin` |

El NDK se busca en `ANDROID_NDK_HOME`, `ANDROID_NDK_ROOT`, `ANDROID_NDK` y en las carpetas
`ndk/<versión>` de `ANDROID_HOME`, `ANDROID_SDK_ROOT` o `~/Android/Sdk` (se usa la versión más
reciente). Siempre puedes forzar uno con `--cc` o `FASET_CC`.

## Salidas

| Objetivo | Ejecutable | Biblioteca (`--shared` / `Library`) |
|---|---|---|
| Linux | `Nombre` | `libNombre.so` |
| Windows | `Nombre.exe` | `Nombre.dll` |
| Android | `Nombre.apk` (o `Nombre` ELF con `--no-apk`) | `libNombre.so` |

`faset run` ejecuta programas para la máquina actual y, con `--target android`, instala y abre el
APK en un dispositivo o emulador. Para Windows desde Linux usa `faset build`.

## Código específico de cada plataforma

Usa la [compilación condicional](/lenguaje/compilacion-condicional/) (`#if WINDOWS`, `#if ANDROID`…)
o pregunta en tiempo de ejecución con `Environment.CurrentPlatform()` / `OS.IsWindows`.

```faset
int main()
{
#if WINDOWS
    println("Compilado para Windows");
#elif ANDROID
    println("Compilado para Android");
#else
    println("Compilado para Linux");
#endif
    println(Environment.CurrentPlatform() == Platform.Linux);
    return 0;
}
```

## Aplicaciones de ventana en Windows

Con `OutputType` `WinExe` (o `--gui`) el `.exe` no abre consola. Las APIs de Win32 se declaran con
`extern` y se enlazan con `-l`:

```bash
faset build examples/ventana_windows.fst --target windows --gui -l user32
```

## Android

`faset build --target android` genera un **APK firmado** con el NDK y las build-tools del SDK, sin
Gradle; `faset run` lo instala, lo abre y muestra su logcat. Consulta [Android](/android/).
