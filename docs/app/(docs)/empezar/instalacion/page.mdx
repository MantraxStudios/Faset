# Instalación

<p className="lead">
  Descarga el paquete de tu sistema: trae el compilador <code>faset</code>, la biblioteca estándar y,
  en Linux, FasetStudio. El instalador deja configurado el <strong>módulo de tu plataforma</strong>
  (el compilador de C que necesita <code>faset</code>) y te ofrece el de Android.
</p>

## Descargar

| Sistema | Paquete | Contenido |
|---|---|---|
| **Linux x86_64** | [faset-linux-x86_64.tar.gz](https://github.com/MantraxStudios/Faset/releases/latest/download/faset-linux-x86_64.tar.gz) | `faset`, FasetStudio, `lib/`, `install.sh` |
| **Windows x86_64** | [faset-windows-x86_64.zip](https://github.com/MantraxStudios/Faset/releases/latest/download/faset-windows-x86_64.zip) | `faset.exe`, `lib/`, `install.ps1` (FasetStudio aún no existe para Windows) |

Todas las versiones están en [GitHub Releases](https://github.com/MantraxStudios/Faset/releases).

### Linux

En una línea (instala en `~/.local`, sin `sudo`):

```bash
curl -fsSL https://faset.lat/install.sh | sh
curl -fsSL https://faset.lat/install.sh | sh -s -- --android   # y Android
```

O a mano, con el paquete descargado:

```bash
tar xzf faset-linux-x86_64.tar.gz
cd faset
./install.sh              # ~/.local/share/faset + ~/.local/bin/faset y fasetstudio
./install.sh --system     # /usr/local (con sudo)
./install.sh --android    # también el módulo de Android (--all: todos)
./install.sh --uninstall  # lo quita
```

El instalador copia los archivos, crea `faset` y `fasetstudio` en `~/.local/bin`, añade FasetStudio
al menú de aplicaciones y ejecuta `faset setup linux`: si falta el compilador de C o alguna biblioteca
de FasetStudio (Vulkan, X11, FreeType) te propone instalarla con el gestor de paquetes (apt, dnf,
pacman, zypper o apk). Después pregunta si quieres el módulo de Android.

El paquete funciona en distribuciones con glibc 2.38 o posterior (Ubuntu 24.04, Debian 13, Fedora 39
o más recientes). También se puede usar sin instalar: `./faset` y `./FasetStudio` desde la carpeta.

### Windows

En PowerShell:

```powershell
irm https://faset.lat/install.ps1 | iex
```

O a mano: descomprime `faset-windows-x86_64.zip` y ejecuta

```powershell
powershell -ExecutionPolicy Bypass -File faset\install.ps1            # -Android para incluir Android
```

Se instala en `%LOCALAPPDATA%\Faset`, se añade al `PATH` del usuario y se ejecuta
`faset setup windows`, que descarga [llvm-mingw](https://github.com/mstorsjo/llvm-mingw) (clang +
MinGW-w64): no hace falta instalar Visual Studio ni MSYS2. Si ya tienes `gcc` o `clang` en el `PATH`,
se usa ese.

<Callout type="aviso">
La versión de Windows del compilador se genera por compilación cruzada desde Linux y todavía no se ha
probado en un Windows real; FasetStudio, el WebView y el VideoPlayer aún no están disponibles allí.
Desde Linux sí se compilan programas para Windows (`faset build --target windows`).
</Callout>

## Módulos de cada plataforma: `faset setup`

`faset setup` instala lo que necesita cada plataforma de destino. Sin argumentos instala el módulo
del sistema en el que estás; `faset setup --list` muestra qué hay sin instalar nada.

| Módulo | Qué instala | Por defecto en |
|---|---|---|
| `linux` | Compilador de C (gcc) y las bibliotecas de FasetStudio, con el gestor de paquetes | Linux |
| `windows` | Toolchain llvm-mingw en la carpeta de datos de Faset: en Windows compila programas nativos; en Linux, compilación cruzada para Windows | Windows |
| `android` | JDK (Eclipse Temurin 21) si no hay Java, Android cmdline-tools, platform-tools, build-tools, la plataforma y el NDK más recientes, el emulador, una imagen del sistema y un AVD | — (opcional, ~4 GB) |
| `multimedia` | WebKitGTK, GStreamer y PulseAudio para `WebView`, `VideoPlayer` y `std.audio` (Linux) | — (opcional) |
| `all` | Todos los que tienen sentido en el sistema | — |

```bash
faset setup                 # el módulo del sistema actual
faset setup android         # SDK, NDK, Java y emulador
faset setup windows         # desde Linux: compilación cruzada para Windows
faset setup --list          # estado de todos los módulos
faset setup android --dry-run   # prepara Java y sdkmanager y muestra qué paquetes instalaría
```

- Antes de instalar, `faset setup` te enseña la orden o la descarga y pregunta. Con `--yes` no
  pregunta y **acepta en tu nombre las licencias del SDK de Android**; sin `--yes`, las lees y aceptas tú.
- Lo descargado va a `~/.local/share/faset` (Linux) o `%LOCALAPPDATA%\Faset` (Windows): `toolchains/llvm-mingw`
  y `jdk/`. El SDK de Android va a `~/Android/Sdk` o `%LOCALAPPDATA%\Android\Sdk` (o a `ANDROID_HOME`), donde
  `faset` y Android Studio lo encuentran. Si ya tienes Android Studio, se reutiliza su SDK y su JDK.
- `faset doctor` muestra lo que se usa al compilar.

## FasetStudio y el CLI

FasetStudio no tiene un compilador propio: usa el mismo `faset` para todo.

| En FasetStudio | Por debajo |
|---|---|
| Compilar y ejecutar (<Kbd>Ctrl+B</Kbd>, <Kbd>F5</Kbd>) | `faset build` / `faset run` con el proyecto, la configuración y el destino elegidos |
| IntelliSense (errores, autocompletado, <Kbd>F12</Kbd>) | el analizador de `faset` (el mismo que usa `faset lsp`) |
| Proyecto nuevo | `faset new` |
| Android (dispositivos, emulador, logcat) | `faset android …` |

FasetStudio busca `faset` en su propia carpeta (y en las superiores), después en la variable `FASET` y
por último en el `PATH`; `faset` busca la biblioteca estándar en `lib/` a su lado (o en `FASET_LIB`).
Por eso el paquete los trae juntos:

```text
faset/
  faset          el compilador (CLI)
  FasetStudio    el IDE
  lib/           biblioteca estándar
  lang/          traducciones del IDE
```

Cualquier cosa que hagas en FasetStudio la puedes repetir en la terminal con `faset`, y al revés.

## Desde el código fuente

### Con make (Linux)

```bash
git clone https://github.com/MantraxStudios/Faset.git
cd Faset
make                    # genera ./faset (usa ./lib como biblioteca estándar)
make studio             # FasetStudio
make test               # ejecuta los tests
sudo make install       # /usr/local/bin/faset + /usr/local/lib/faset
scripts/dist.sh         # paquetes de dist/ (los mismos que se descargan arriba)
```

`make install` copia el compilador en `$(PREFIX)/bin` y la biblioteca estándar en
`$(PREFIX)/lib/faset` (por defecto `PREFIX=/usr/local`). Si prefieres no instalar nada, usa
`./faset` directamente desde la carpeta del repositorio.

### Con CMake (Windows o cualquier sistema)

```bash
cmake -B build && cmake --build build
```

## Requisitos por plataforma de destino

| Objetivo            | Necesitas                                                        | Lo instala               |
|---------------------|------------------------------------------------------------------|--------------------------|
| Linux               | `gcc` o `clang`                                                  | `faset setup linux`      |
| Windows             | MinGW-w64 o `clang` (llvm-mingw)                                 | `faset setup windows`    |
| Windows desde Linux | MinGW-w64 o llvm-mingw                                           | `faset setup windows`    |
| Android             | Android SDK + NDK y Java                                         | `faset setup android`    |

Para compilar **FasetStudio** hacen falta además las bibliotecas de desarrollo de X11 y FreeType y
el cargador de Vulkan (`libvulkan.so.1`). Consulta [FasetStudio](/studio/introduccion/).

## Comprueba la instalación

`faset doctor` muestra dónde encontró la biblioteca estándar y qué compiladores de C detecta:

```bash
$ faset doctor
Faset 0.3.0  (host: linux-x86_64)

  Biblioteca std             /home/usuario/Faset/lib
  Nativo (linux)             /usr/bin/cc
  Windows x86_64 (MinGW)     no encontrado  -> faset setup windows
  Android NDK                /home/usuario/Android/Sdk/ndk/30.0.16248370
```

<Callout type="consejo">
Si `faset` no encuentra la biblioteca estándar (por ejemplo, porque moviste el ejecutable), define
la variable `FASET_LIB` con la ruta de la carpeta `lib/`. Para elegir otro compilador de C usa
`--cc` o la variable `FASET_CC`.
</Callout>

## Hola, mundo

```faset
// hola.fst
int main()
{
    println("¡Hola, Faset!");
    return 0;
}
```

```bash
faset run hola.fst            # compila y ejecuta
faset build hola.fst -c Release   # ./hola, optimizado (-O2)
```
