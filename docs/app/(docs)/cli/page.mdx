# Línea de órdenes (CLI)

<p className="lead">
  <code>faset</code> es compilador, gestor de proyectos y servidor de lenguaje en un solo ejecutable.
  Las tablas de esta página se generan a partir de la salida de <code>faset help</code> en cada
  compilación de la documentación.
</p>

## Órdenes

<CliCommands />

**Entrada**: un `.fstproj`, una carpeta con un `.fstproj`, o archivos `.fst` sueltos. Sin entrada se
usa el `.fstproj` de la carpeta actual. También vale `faset archivo.fst` como atajo de
`faset build archivo.fst`.

## Opciones

<CliOptions />

Las opciones de la línea de órdenes tienen prioridad sobre las del `.fstproj`.

## faset new

```bash
faset new MiApp              # consola
faset new Utilidades --lib   # biblioteca
faset new MiVentana --winexe # ventana de Windows
faset new MiApp --ui         # AppUI con std.ui (.fstui + código)
faset new MiMovil --android  # app de Android (std.ui + .fstui)
faset new Hola --android --console   # Android sin interfaz: la consola va a logcat
```

Crea `Nombre/Nombre.fstproj`, el código inicial y un `.gitignore`. Consulta
[Tu primer proyecto](/empezar/primer-proyecto/) y [Android](/android/). `faset new Nombre --lib --package`
crea una biblioteca lista para publicar como [paquete](/empezar/paquetes/#crear-y-publicar-un-paquete).

## Paquetes: add, remove, restore, update

```bash
faset add https://github.com/usuario/json5-faset --version "^1.2"   # o un nombre del índice, o ../carpeta
faset remove Json5
faset restore                  # lo que diga paquetes.lock (sin red si está en la caché)
faset update [Json5]           # versiones nuevas compatibles
faset list paquetes            # árbol resuelto (--json)
faset pack                     # valida los metadatos de un paquete y muestra cómo publicarlo
```

`faset build` y `faset run` restauran solos los paquetes que falten. Todas aceptan
`--project <x.fstproj>`, `--offline` e `--index <url>`. Consulta [Paquetes](/empezar/paquetes/).

## faset build

Compila a un ejecutable nativo en `bin/<Configuración>/<plataforma>-<arquitectura>/`.

```bash
faset build -c Release
faset build --target windows --arch x86_64
faset build programa.fst -o salida --static
faset build --sanitize         # ASan + UBSan
faset build -c Release --checks   # Release con los diagnósticos de 'delete' de Debug
faset build --allow-unsafe     # todo el proyecto como memory_unsafe
faset build --target android   # APK firmado en bin/<Config>/android/
faset build -v                 # muestra la orden del compilador de C
faset build -c Release -g      # Release con información de depuración (líneas de Faset)
```

`Debug` compila el C con `-O0 -g` y `Release` con `-O2`. Las [comprobaciones en ejecución](/lenguaje/seguridad-de-memoria/#comprobaciones-en-ejecucion)
(nulos, índices de cadenas, divisiones por cero) están activas en las dos; `Debug` añade los
[diagnósticos](/lenguaje/seguridad-de-memoria/#diagnosticos-de-debug) de uso después de `delete` y
`delete` doble (`--checks` / `--no-checks` lo cambian). Siempre se usa
`-std=c11 -fwrapv -fno-strict-aliasing`.

En `Debug` el C lleva además directivas `#line N "archivo.fst"`, así que gdb y lldb trabajan con las
líneas de tus `.fst` (puntos de interrupción, paso a paso, pila). `-g` / `--debug-info` las añade
también en `Release` y `--no-debug-info` las quita. Es lo que usa el
[depurador de FasetStudio](/studio/depurador/).

## faset run

Compila y ejecuta. Lo que va después de `--` se pasa a tu programa. Con `--target android` (o un
proyecto con `TargetPlatform` `android`) compila el APK, lo instala en el dispositivo
(`--device <serie>`), lo abre y sigue su logcat hasta que termina; devuelve su código de salida.

```bash
faset run
faset run juego.fst -- --nivel 3
faset run --target android --device emulator-5554
```

Si el programa termina con un `Faset panic`, el código de salida es 101.

## faset check

Comprueba errores sin generar el ejecutable: tipos, sobrecargas, plantillas usadas, accesibilidad,
rutas de retorno… Es rápido y útil en integración continua.

## faset emit-c

Escribe el C11 intermedio en la salida estándar o en un archivo:

```bash
faset emit-c hola.fst -o hola.c
faset emit-c -g hola.fst -o hola.c   # con las directivas #line de depuración
```

`faset build --keep-c` conserva el C junto al ejecutable.

## faset clean

Borra `bin/` y `obj/` del proyecto.

## faset android

```bash
faset android devices                 # serie<TAB>estado<TAB>modelo
faset android avds                    # emuladores instalados
faset android emulator <avd> --headless   # arranca, espera e imprime la serie
faset android logcat --app            # logcat de la app del proyecto
faset android stop | uninstall        # detiene / desinstala la app del proyecto
```

`faset android help` muestra todas las opciones. Consulta [Android](/android/#ordenes-faset-android).

## faset doctor

Muestra la biblioteca estándar encontrada, los compiladores de C detectados para Linux y Windows
(MinGW) y, para Android, el SDK, el NDK, las build-tools, la plataforma, `adb`, el emulador, Java y los
AVD. Consulta [Instalación](/empezar/instalacion/#comprueba-la-instalacion).

## faset lsp

Servidor de lenguaje por la entrada y salida estándar, para VS Code, Neovim, Helix, Zed, Sublime y
otros editores. Consulta [Editores y LSP](/empezar/editores/).

## Variables de entorno

| Variable | Uso |
|---|---|
| `FASET_LIB` | Carpeta `lib/` con la biblioteca estándar, si `faset` no la encuentra solo. |
| `FASET_CC` | Compilador de C a usar (igual que `--cc`). |
| `ANDROID_NDK_HOME`, `ANDROID_NDK_ROOT`, `ANDROID_NDK`, `ANDROID_HOME`, `ANDROID_SDK_ROOT` | Dónde buscar el NDK. |
| `JAVA_HOME` | Java para `apksigner`/`keytool` (si no, `java` del `PATH` o el JBR de Android Studio). |
| `FASET_ANDROID_KEYSTORE_PASSWORD`, `FASET_ANDROID_KEY_PASSWORD` | Contraseñas del keystore de firma de Android. |
| `FASET_PANIC_ABORT` | Con `1`, un `Faset panic` llama a `abort()` (para depurar con gdb). |
| `FASET_UI_SCREENSHOT`, `FASET_UI_SCRIPT` | Aplicaciones `std.ui`: dibujar sin pantalla y guardar una captura `.bmp`. |
| `FASET_STUDIO_LANG` | Idioma de FasetStudio (`es`, `en`…). |
| `FASET_STUDIO_GPU` | `cpu` fuerza Vulkan por software (lavapipe) en FasetStudio. |
| `FASET_PAQUETES_INDICE` | URL o ruta del [índice de paquetes](/empezar/paquetes/#el-indice-de-paquetes) (por defecto `https://faset.lat/paquetes/index.json`). |
| `FASET_OFFLINE` | Con `1`, los paquetes solo salen de la caché y de `paquetes.lock` (nada de red). |
| `FASET_PAQUETES_CACHE` | Carpeta de la caché de paquetes en vez de `~/.local/share/faset/paquetes`. |
